# 局域网聊天室

一个不需要任何第三方依赖的局域网聊天室：**Python 标准库服务器（SQLite 存储）+ 网页 + 安卓 App**。
电脑当服务器，同一个 WiFi 下的手机和电脑打开网页或 App 就能聊天。

> 适合课程设计 / 宿舍局域网使用，也可以当作「从零实现一个 IM」的学习项目。

## 功能

**聊天**
- 多房间（像微信群）：所有人可建、所有人可见，房间之间消息与已读完全隔离
- 文字消息 + 图片消息（自动压缩，点开看大图）
- 自定义头像（按设备保存，其他端自动刷新）
- 已读回执（未读 / 已读 1/2 / 全部已读）
- 消息撤回（2 分钟内）、消息编辑（10 分钟内，带「已编辑」标记）
- 未读数量与「上次读到此处」分隔线
- 历史记录翻页（每房保留最近 500 条，超出有明确提示）

**稳定**
- 离线补消息：断线重连按版本号增量补齐
- 发送失败重试：同一条消息重试不会重复
- 连接状态与自动重连：退避重试，断线时人数显示「—」
- 服务器重启后客户端自动重新登记，历史与已读位置不丢
- 输入校验：空 / 超长 / 太快，都有中文原因

**其它**
- 在线人数按「人（浏览器/设备）」去重，多开窗口只算 1 人
- 微信风界面，桌面端双栏、手机端列表/聊天两屏

## 下载

- **安卓 App**：到 [Releases](../../releases) 下载 `chatroom-v3.apk`（已签名，直接安装）
- **服务器 + 网页**：克隆本仓库即可，无需安装任何 Python 包

> 推送 `v*` 标签时，`.github/workflows/release.yml` 会自动创建 Release，
> 并把仓库里的 `dist/chatroom-v3.apk` 作为附件上传。
> 重新构建 APK 后，把它复制到 `dist/` 一起提交，再打新标签即可。

## 快速开始（Windows）

1. 安装 Python 3.11+（推荐 [uv](https://github.com/astral-sh/uv)：`uv venv --python 3.11`）
2. 双击 **`启动聊天室.bat`**，会弹出服务器黑窗口并自动打开浏览器
3. 黑窗口会打印访问地址，例如：
   ```
   局域网访问: http://192.168.1.209:9999
   ```
4. 其他人用浏览器打开这个地址；手机也可以装 App 后点「自动查找」连接
5. 第一次启动 Windows 会弹防火墙提示，**点「允许访问」**（否则别人连不上）

停止服务：关掉黑窗口，或按 `Ctrl + C`。

## 安卓 App

1. 从 Releases 下载 APK，传到手机安装（允许「安装未知来源应用」）
2. 手机和电脑连**同一个 WiFi / 热点**
3. 打开 App → 点 **「自动查找」**（服务器会应答 UDP 广播，换 IP 也不用改地址）
4. 自动查找失败时，手动填黑窗口里打印的地址（如 `192.168.1.209:9999`）

App 是 WebView 外壳，功能与网页完全一致；发照片/换头像走系统文件选择器，不需要存储权限。

## 技术要点

- **增量同步**：每条消息带全局递增 `rev`，客户端每秒带 `lastRev` 请求 `/state`，
  服务器只返回变化（新消息、编辑、撤回都覆盖），客户端按消息 id 合并。
- **幂等发送**：消息带 `msg_uuid`，服务器用唯一索引去重，重试不会产生第二条。
- **数据库**：SQLite，表 `rooms / messages / message_audience / read_positions / avatars / images / meta`；
  索引 `(room_id, rev)`、`(client_id, uuid)`；每次变更只写受影响的行。
- **图片**：客户端先压到最长边 1600px / ≤1.5MB；图片走 `/image?message_id=&v=` 独立端点，
  URL 带版本号 + 长缓存，不进每秒轮询。
- **头像**：按设备存 128px，版本号递增，`/state` 只送版本表，前端靠版本刷新缓存。
- **身份**：`client_id`（每个标签页，sessionStorage，负责心跳）+ `device_id`
  （每个浏览器，localStorage，负责人数去重与归属）。

更细的说明见 [设计说明.md](设计说明.md) 与 [原理讲稿.md](原理讲稿.md)。

## 已知边界

- 局域网使用，明文 HTTP，没有账号体系；身份按浏览器（设备）计算
- 实时性是「1 秒内可见」的轮询，不是 WebSocket 毫秒推送
- 房间不支持删除 / 改名 / 私密 / 密码
- 图片存在数据库里，`chat.db` 会随图片增长；不支持视频、语音、文件
- 撤回无法收回已经被看到或截屏的内容
