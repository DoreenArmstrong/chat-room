# 💬 局域网聊天室（Chat Room）

一个**零依赖**的局域网聊天室：只用 Python 标准库写服务器 + 一个 HTML 页面做界面，不需要安装任何第三方包。

- 你的电脑当服务器，连在**同一个 WiFi / 路由器**下的人都能进
- 支持昵称、实时消息、进出提示，界面适配手机和电脑
- 核心逻辑只有约 150 行服务器代码 + 一个页面，适合学习"前后端是怎么通信的"

## 快速开始

双击 `启动聊天室.bat`（或在命令行运行 `python server.py`）。

- 会弹出一个黑窗口（服务器，**保持开着别关**）并自动打开聊天页面
- 黑窗口里能看到每个人的访问和发言记录

## 让别人加入

同一局域网内的任何设备（手机、别人的电脑），用浏览器打开：

```
http://192.168.1.209:9999
```

> IP 以你机器当前的实际 IP 为准，在命令行运行 `ipconfig` 查看"IPv4 地址"。
> 换了 WiFi / 网络后 IP 可能变化，记得重新查。

### 第一次启动：放行防火墙

第一次运行时 Windows 会弹出"Windows 安全中心警报"，点 **允许访问**（把"专用网络"勾上）。
如果当时点了取消，别人会打不开页面，用管理员身份执行一次：

```
netsh advfirewall firewall add rule name="ChatRoom 9999" dir=in action=allow protocol=TCP localport=9999
```

## 工作原理（1 分钟版）

1. 浏览器打开 `http://IP:9999`，服务器把 `index.html` 发过去 —— 这就是"网站"
2. 页面里的 JavaScript **每 1 秒**问服务器一次："有新消息吗？"（`GET /messages`）
3. 你点发送，页面把消息 `POST /send` 给服务器，服务器存进内存
4. 其他人下一次轮询就能拿到这条新消息并显示出来

这个套路叫 **轮询（polling）**。真实产品（微信网页版等）多用 WebSocket 长连接，消息能做到毫秒级直达，但代码复杂不少，可以作为下一步的学习方向。

## 接口一览

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/` | 返回聊天页面 |
| POST | `/join` | 进入聊天室（广播"xx 加入了聊天室"） |
| POST | `/send` | 发送一条消息 |
| GET | `/messages?after=N` | 拉取编号大于 N 的新消息 |
